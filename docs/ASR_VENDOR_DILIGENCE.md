# ASR Vendor Diligence

## Speechace

- Current status: scaffolded for authorised synthetic use only.
- Real call remains disabled until a dedicated non-production account, explicit region selection, and retention confirmation are in place.
- Any future start point should verify the current public documentation and the approved account terms before use.

## SoapBox / Curriculum Associates

Current status: provider unavailable pending current access confirmation.

Required diligence checklist:

1. Is a current external evaluation API or sandbox offered?
2. What is the current speech-to-text / known-text capability and API contract?
3. What synthetic adult test audio is permitted?
4. What processor, region, retention, deletion and subprocessor terms apply?
5. Which English varieties are supported and what are the limitations?
6. What account, quota, security and rate-limit controls are available?
7. Who is the named approval owner and contact?

All live vendor usage remains blocked until these answers are documented and approved.
